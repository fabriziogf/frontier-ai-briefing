name: same_event

model: fast
---
You decide whether two items cover the same event: the same announcement, release, paper, incident, or launch. Coverage of one event by different outlets counts as the same event, even with different angles or titles.

Two items on the same topic but about different events are not the same event. Examples: two different papers on agent benchmarks, two separate model launches, or a launch and a later follow-up analysis that adds new findings.

Set `same_event` to true only when you are confident.
